# 窗户 ANC 可行性 — 因果限制、实测与实现方案

> **整合自**: `因果性限制与窗户ANC可行性_参考.md`(2026-08-03 理论) + `2026-08-04_实时ANC实测与窗口降噪规划.md`(实测) + 2026-08-05 DSP 可行性分析
> **背景**: 目标是对 **123×45cm** 窗户开口实现 **20-1000Hz 马路噪音**主动隔声(整窗声压 →0 为理想极限;务实主攻 20-500Hz,8 扬声器空间采样上限 ≈400-500Hz,详见 §4.3 通用换算)。架构方向 2026-08-13 转向**开环前馈**(误差麦仅安装标定用,运行时拆掉,参考 SFANC-Window,详见 §5)。
> **核心问题**: 前馈 ANC 的因果性(预览时间)决定宽带降噪上限;当前 PC 原型被 12.5ms 声卡延迟锁死。

---

# 第一部分:因果性限制(理论)

## 1. 预览时间(causality / preview time)

前馈 ANC 能否抵消宽带随机噪声,由**预览时间**决定:

```
预览时间 = 参考麦→误差麦声学延迟 − (处理链延迟 + 扬声器→误差麦声学延迟)
```

- **预览时间 > 0** → 参考麦提前听到噪声,控制器有"提前量" → 宽带可实时对消(频率上限受预览大小限制)。
- **预览时间 < 0** → 反噪声比噪声晚到误差麦 → 随机宽带不可对消(只能消窄带/周期 + 部分低频)。

**当前 PC 系统实测值**:

| 分量 | 值 |
|------|-----|
| 参考→误差声学延迟(64cm / 343) | +1.9ms |
| ANC 带通群延迟(64tap, 2026-08-04 砍短前 256tap=−8ms) | −2ms |
| 声卡环路延迟(UMC ASIO, 128 样本缓冲,实测) | −8.4ms |
| 扬声器→误差声学延迟 | −0.4ms |
| **净预览** | **≈ −9ms**(砍带通前 −18.5ms) |

> 因果缺口为负 → 对随机宽带(相关时间 < 缺口,即 >~55Hz 宽带)不可实时对消;<55Hz 宽带 + 窄带/周期成分可消。**这就是实时 NR 只到 4-6dB 的根本原因。**

## 2. 两种"延迟"不能混淆

| 延迟 | 值 | 有没有问题 |
|------|-----|-----------|
| **CNN→Wc 交接**(慢环路,1Hz) | 1 秒 | ✅ **无问题**——CNN 是"暖启动"(提供 Wc 起点),FxLMS 每样本持续追当前噪声 |
| **前馈处理链**(快环路,每样本) | ~12.5ms | ❌ **这才是问题**——反噪声到达时间被物理链路锁死,与 Wc 无关 |

**关键认知**: Wc(控制滤波器)只决定反噪声的**形状**(频率/相位),**不决定到达时间**。无论 Wc 多准、CNN 多快,反噪声都要走处理链。场景降噪帮的是"可预测"噪声(窄带/周期/缓慢变化),对随机宽带无用。

# 第二部分:窗户 ANC 论文对照(Lam et al. 2020)

论文在 1m×1m 全尺寸家用窗上实现 **7.51-10.14 dB**(能量平均 SPL)真实宽带城市噪声降噪。它做到的 10dB 与当前系统条件**根本不同**:

| 条件 | 论文 | 当前 PC 原型 |
|------|------|---------|
| 扬声器数 | **24 个** 4.5cm 小扬声器铺满窗洞 | 2 个 |
| 误差麦 | 运行时**不装**(离线 FxLMS 训练固定 FIR) | 3 个,持续自适应 |
| 参考麦 | 单个,**窗户外侧**(朝噪声源) | 1 个,距误差麦 64cm |
| 控制器 | 实时 **DSP,~ms 级低延迟** | PC + UMC,12.5ms 环路 |
| 控制频段 | **300Hz-1kHz 有效,500Hz 以上最强,<300Hz 几乎无效**(小扬声器低频效率差) | <300Hz + 全频段窄带 |

**为什么论文能、当前不能**:

```
论文: 预览(窗外 3-6ms) − (DSP ~2ms + 扬声器 ~0.5ms) = 余量正 → 300Hz-1kHz 可控
当前: 预览(1.9ms) − (12.5ms + 0.4ms) = 负 → 中高频宽带不可控
```

**决定性差异 = 那 12.5ms 声卡延迟。** 论文用低延迟 DSP,PC 声卡把因果性吃光了。参考麦 64cm(1.9ms 预览)并不算短,被声卡延迟拖垮 —— **关键在延迟,不在参考麦距离。**

> 论文 10dB 是**中频段(300Hz-1kHz)**,500Hz 以上最强,<300Hz 几乎没控制(小扬声器限制) —— 与早期"控低频"正好**互补**,不是全频段 10dB。论文用 24 通道做**空间声场控制**(让窗洞成为声压释放边界),这是 2 扬声器做不到的。
> **对我们的启示**: 论文证明**中频(300-1000Hz)用小喇叭阵列可行(~10dB)**——而这正是现代车外噪主体(胎噪)的频段,详见 §4.6。

# 第三部分:实时实测与硬件调试(2026-08-04/05)

## 3.1 灵敏度根因:模拟增益旋钮,不是软件

- "不贴麦不收音"根因 = UMC 输入旋钮太低。旋钮拧到最大后 ref 自然到 -30dBFS,自动增益回 1x。
- 旧参数(wc_target=0.03 / step=3e-7 / MIC_GAIN=20 / DIVERGE_ANTI=5)是弱信号期诊断兜底,**在信号健康时全部失效**,已废弃。
- 注意机制:发散救援阈值 = `diverge_anti_rms / mic_pre_gain`,mic_pre_gain=20 时阈值被压到 0.0125 → NR 卡死。

## 3.2 校准质量规则

- 校准时 **SIG 常亮、CLIP 不亮**。CLIP = ADC 削波(数据进程序前,不可逆),污染路径辨识。
- 探针响度 `GFANC_CAL_NOISE`(默认 0.9,反馈+次级都支持),旋钮最大时用 0.4-0.5。
- **校准和运行必须同一旋钮位置**(路径系数嵌入模拟增益)。
- ERLE<8dB 弱路径自动置零(保护),失败路径每次校准会漂移(e0,s0 / e1,s1)。

## 3.3 125Hz 反馈振荡

**机理**: 扬声器反噪音→误差麦听到→FxLMS 当"要消的噪音"继续消→正反馈环。12.5ms 纯延迟反馈环天然在 `1/(2τ)≈40Hz` 及奇次谐波(120/200Hz)起振 —— **125Hz 是延迟自激,与外部声源无关**。

**铁证**: 陷波 ON(默认阈值 12)→ 稳定;陷波 OFF(HW_THRESH=15)→ 周期性"收敛→err=0.7 爆炸→静音"。

**处理**: ①误差麦旋钮降到 SIG 能亮(别降过);②扬声器与误差麦拉开/错向;③陷波保持默认兜底。

## 3.4 环路延迟构成与砍法

```
环路 12.5ms = ASIO 管线 8.4ms(128 样本@48k=2.67ms 只是部分)+ Ŝ 声学 4ms(物理)
```

| 杠杆 | 省 | 状态 |
|---|---|---|
| 带通 256→64tap | ~6ms(8→2ms) | ✅ 已改 |
| 参考麦往窗外移 | 预览 1.9→3ms+ | 物理,免费 |

## 3.5 算法优化(2026-08-05,commit 04b6444)

| 改动 | 效果 |
|---|---|
| **VS-LMS(双 EMA 尖峰检测)** | 误差相对基线跳变→降步防反馈过冲,平滑收敛全速。实时 step 3e-7/5e-7 从"7次MUTE振荡"变稳定 |
| **leak 默认 5e-6→5e-7** | 弱信号下 Wc 能长起来(离线 1.4→13dB 的收敛杠杆) |
| **虚拟延迟/预览**(`GFANC_VIRT_DELAY_MS`/`GFANC_VIRT_PREVIEW_MS`) | 离线验证因果性:延迟→Ŝ,预览→Pri |

**验证结果(离线,马路噪音):**

| 配置 | NR_true |
|---|---|
| 无延迟(算法上限) | 13.1dB |
| **预览 3ms + 延迟 ≤2ms(窗口场景)** | **~15dB** ✅ |
| 预览 3ms + 延迟 5ms | 7.1dB |
| PC 现状(延迟 12.5ms) | ~6dB(印证实时) |

> ⚠️ **口径说明(2026-08-07)**: 上表为**离线 NR_true**——干净模型、无硬件环路、误差麦单点/算法上限。**实时整窗"能量平均" NR 远低于此**(空间欠采样+相干性): 2S≈2-4dB、6S≈5-9dB(详见 §5.2 双口径)。"整窗声压→0"是**理想极限,非可达指标**(Lam 2020 用 24 单元也仅 ~10dB)。

**实时**: 默认 NR 4.4→**6.2dB**,高步长稳定。**实时 NR 是"诚实NR"估计**(`pd=Σ(err-anti_est)²` 反推,依赖 Ŝ;口径 bug 已修 BUG-1/R-58 但仍非真值,误差麦降太狠读数会触底),唯一真值 = 离线 `nr_true`(Pri 模型),实时以人耳为准。

## 3.6 实机降噪能力实测(2026-08-10,校准+相位修复后)

**测试口径**: 次级路径 `secondary_path_measured.bin`(v4,6 条 S 全过 ERLE≥12.9dB);环路延迟 201 样本=12.56ms 实测;新默认 OCG 关 + `switch_threshold=0.6`(commit bdf7639)。指标 = 误差麦实测残差 RMS(err),NR 为模型估计仅参考。

| 声源 | 基线 err | 稳态 err | 降噪 | 保持 |
|---|---|---|---|---|
| **250Hz 纯音** | ~0.10 | **0.015** | **~16.5dB** | 40s+ 零 RESET |
| **500Hz 纯音** | 0.10-0.19 | **0.018** | **~15-20dB** | 全程零 RESET/MUTE |
| **马路噪声宽带** | — | err/ref≈0.30 | **~10dB** | ~2min 零发散 |

- **之前震荡根因(已修)**: 默认 reset 闸门 0.80 在深对消时误杀健康 Wc(cos 随 anti 增长自然跌破 0.8),降到 0.6 + 关 OCG 后 cos 全程 ≥0.65,零误杀,深对消稳住。
- **宽带只 10dB 的原因**: 高频段预览预算为负(§1),只能消 <55Hz 宽带 + 窄带/周期成分。

**三个独立瓶颈(嵌入式只解决第一个)**:

| 瓶颈 | PC 现状 | 嵌入式 | 平台无关? |
|---|---|---|---|
| **A 环路延迟** | 12.5ms(PC+USB+Windows) | 1-3ms(DSP/FPGA) | ❌ 可解决 |
| **B 声学前瞻**(ref→误差区) | ~1.9ms(≈65cm) | 取决于布局 | ⚠️ 靠挪麦,与平台无关 |
| **C 扬声器低频滚降**(<100Hz 掉 ~25dB) | 存在 | 存在 | ❌ 需换低音单元/密封箱体 |

**结论**: 换嵌入式主要收益 = 可消频段从 <55Hz 扩到 100Hz-1kHz,宽带整体 10→10-15dB;**突破 10dB 宽带的决定性杠杆是扬声器单元数(阵列铺满窗面),不是平台**。

# 第四部分:DSP 可行性分析(2026-08-05 新增)

## 4.1 2ms 环路延迟预算

| 组成 | 通用音频 codec | **ANC 级低延迟 codec** |
|---|---|---|
| ADC 转换 | 0.5-1ms | 0.2-0.5ms |
| DSP 处理(逐样本中断) | ~0.1ms | ~0.1ms |
| DAC 转换 | 0.5-1ms | 0.2-0.5ms |
| 环路滤波(最小相位) | 0.2-0.5ms | 0.2-0.5ms |
| **合计** | **1.3-2.6ms ⚠️ 紧/超** | **0.7-1.6ms ✅** |

**结论:2ms 可实现,但必须 ANC 级低延迟 codec**(ADAU1787 或高速 I2S 转换器)。通用 codec 的 1-2ms 转换延迟直接吃光预算。

## 4.2 通道数算力(通用关系,最终 8spk/8mic 精确算力见 §4.8)

MIMO FxLMS 算力 ∝ E×S×L,**与通道数平方级增长**(8spk/8mic = 64 条路径)。当前 PC 原型 ~0.2-0.3 GMAC/s(2S+3E+1024L),扩到 8spk/8mic 后前馈 FxLMS 达 3.48 GMAC/s(§4.8 逐模块明细)。

**关键认知: 2ms 延迟与通道数无关** —— codec 延迟每通道固定,处理延迟是"一个采样周期内算完全部通道",通道多只加算力不加延迟。所以扩通道的代价是**算力/成本**,不是延迟。

> 早期(2026-08-07)评估过多款 DSP(C6748/SHARC/ADAU1467/FPGA),唯一要记的教训: ⚠️ **ADAU1467 是 SigmaDSP 图形化编程,不能跑现有 C 代码**(需重写 SigmaStudio 框图)。最终主控定 **RK3568(4×A55)**(§4.8.3),控制率 16kHz(48kHz 解码器 3:1 抽取)。

## 4.3 扬声器数量与空间上限(123×45cm 窗,2026-08-13)

两条独立法则,结论互相印证:

**法则① λ/2 空间采样(周边布置)**: 频率上限 `f_max = c / (2 × 间距)`;周边布置 `间距 = 开口周长 / 扬声器数`。123×45cm 窗周长 336cm,8 扬声器间距 42cm → `f_max = 343 / (2×0.42) ≈ 408Hz`。

**法则② 矩形波导模式数(整面控制)**: 透过开口的声场展开为模式,控制声场 = 控制主导模式。模式数 `N ≈ (k·a/π + 1)(k·b/π + 1)`,k = 2πf/c,a/b 为开口两边长。123×45cm:

| 频率 | λ | λ/2 间距 | 周边 8 源(42cm) | 模式数(≈独立源需求) |
|---|---|---|---|---|
| 200Hz | 171cm | 86cm | ✅ | ~4 |
| 400Hz | 86cm | 43cm | ⚠️ 刚好 | ~8 |
| 500Hz | 69cm | 34cm | ❌ | ~10 |
| 1000Hz | 34cm | 17cm | ❌ | ~24-30 |
| 1500Hz | 23cm | 11cm | ❌ | ~50+ |

**结论(2026-08-13)**: 8 扬声器 + 8 误差麦有效控制上限 ≈ **400-500Hz**(两法一致);覆盖马路噪音主体(轮胎-路面噪声峰值 100-400Hz);1000Hz 需 ~20-24 源。**开窗场景玻璃不起隔声作用**(窗户开着): >500Hz 噪声直接通过开口漏入,ANC 采样不足又无玻璃兜底 → 该频段纯漏,要覆盖只能加通道(空间采样代价大)。**误差麦数须 ≥ 扬声器数**(MIMO 解耦)。严格"整面连续声压=0"不可达(需无限密集源+全频段),但控主导模式即可大幅降低透过开口的总辐射声功率。

## 4.4 参考麦相干性约束(预览 vs 预测的权衡)

参考麦要预测误差麦处的扰动,靠**相干性**。距离越远:
- 预览↑(因果裕量)✅
- 相干性↓(高频预测变差)❌

**频率相关的**: 场在距离 d 内失相关,相干良好上限 ≈ c/d。

| 参考→误差 | 预览 | 相干良好上限 | 500Hz 预测 |
|---|---|---|---|
| 50cm | 1.46ms | ~686Hz | ✅ |
| **1m** | 2.9ms | **~343Hz** | **失相关,消不动** |
| 2m | 5.8ms | ~170Hz | ✗ |

**关键结论**: 单参考麦放 1m,在 500Hz 已失相关(相干上限 ~343Hz < 500Hz)。目标 20-500Hz 需参考麦**足够靠近窗面**(<50cm)或上**参考阵列**补高频相干性——这是 Phase-1.5 需实测的阻塞项。

## 4.5 嵌入式移植关键优化(延迟/算力)

> PC 原型的 8.4ms ASIO 是驱动/声卡级硬瓶颈,代码改不动;嵌入式**逐样本架构**直接消掉 2.7ms 块缓冲(GFANC_BUFFER=128),是最大延迟解放。

**2ms 延迟的 3 个硬条件**: ① ANC 级低延迟 codec(ADAU1787/高速 I2S;通用 codec 1-2ms 转换直接吃光预算);② 逐样本处理(非块缓冲);③ DSP 峰值吞吐 > 需求。

**算力**: 当前 ~0.3 GMAC/s 不是瓶颈;扩到 8spk/8mic 后 FxLMS 是大头(§4.8)。最大降本杠杆 = **L 1024→512**(FxLMS 算力减半,频域分辨率 15.6→31Hz 对 20-500Hz 仍够,需重训 `sub_filters.bin`)+ **SIMD**(双段循环零取模已 SIMD 友好)。

## 4.6 目标噪声频段分析(2026-08-07,居民视角)

### 4.6.1 居民楼听到的三类马路噪声

| 声源 | 主要频段 | 特征 |
|---|---|---|
| **车噪**(发动机/排气/车流) | 50-400Hz | 低频"轰隆"; **但现代车(尤其电车)发动机已很安静** |
| **胎噪**(轮胎-路面) | 500-2000Hz(全谱) | 中频;车速>40-60km/h 后是车流主成分 |
| **人声/市井嘈杂** | 300-3400Hz | 中高频,说话清晰度靠此段 |

**关键认知**: 现代汽车(尤其电车)发动机噪声被压制得很低 → **车外噪声主体 = 胎噪(中频)**,不是低频轰鸣。
人耳对 500Hz-4kHz 最敏感(A 计权),所以最"吵"的是中频胎噪 + 说话声。

### 4.6.2 夜晚远处单车的实际听感

城区夜晚安静街,30-50 迈(48-80km/h)车辆远处驶来:
- **是胎噪,不是风噪**——速度分界: 乘用车 30-50 迈时胎噪主导;风噪需 >110km/h(70 迈);发动机现代车几无声。
- **距离低通效应**: 远处传来时胎噪高频分量被大气吸收/地面效应衰减 → 听到的是**低通后的胎噪,主能量 ~100-800Hz**。

### 4.6.3 目标设定: 马路噪音 20-1000Hz(2026-08-13 修订)

- **目标频段**: **20-1000Hz 马路噪音**(2026-08-13 实机调试后确认);务实主攻 **20-500Hz**——8 扬声器空间采样上限(§4.3 通用换算),覆盖路噪能量主体(轮胎-路面噪声峰值 100-400Hz)。
- **历史修订**: 早期"低频轰鸣 50-400Hz" → 2026-08-07"中频胎噪 100-800Hz" → 2026-08-13"马路噪音 20-1000Hz(务实 20-500Hz)"。
- **开窗场景无玻璃兜底**: 窗户打开时玻璃不参与隔声,全频段噪声直接通过开口传入。>500Hz(8 扬声器采样上限,§4.3)ANC 消不动、玻璃也不挡 → 该频段纯漏入;要覆盖 1000Hz 需 ~20-24 源(空间采样代价大),需在通道数与频段目标之间取舍。
- **相干性**: 定向车流(平面波式)在窗外参考下中频相干可行(Lam 2020 实测 300-1000Hz ~10dB);居民楼多径反射会降低相干性 → **必须实测验证**(阻塞项)。
- **扬声器**: 低频(<100Hz)需大口径/大行程(体积位移大),但马路噪音 <100Hz 能量低可放宽下限至 ~50Hz;中频用小口径(4.5-8cm)高效——**反面教训: Lam 用 4.5cm 小喇叭低频(<300Hz)几乎无效,但中频 300-1000Hz 做到了 ~10dB**。

## 4.7 麦克风选型标准(2026-08-07,ECM8000 教训)

**背景**: 项目此前用 ECM8000(-70dB 测量麦)当参考/误差麦,**实际应用不行**——低灵敏度需最大增益、噪声底高、
位置极敏感、不防水。**窗口 ANC 的麦克风是实用传感器,不是测量仪器**;选错会污染 Ŝ/环路/NR 全部测量。

| 要求 | 参考麦(窗外) | 误差麦(窗内) |
|---|---|---|
| **灵敏度** | **≥ -45dB**(越高越好,免极端增益) | ≥ -45dB |
| **频响** | **100-800Hz 平坦**(±3dB 内即可) | 同 |
| **防水/耐候** | **必须**(窗外日晒雨淋) | 不需要 |
| **噪声底** | 低(A 计权 ≤ ~30dB SPL) | 同 |
| **尺寸** | 小、易固定 | 小、易固定 |

**推荐类型**: 高灵敏度驻极体电容(MEMS/预极化)或专用户外麦克风;**避免测量级麦克风**(ECM8000 等,
-60~-70dB 低灵敏度为频响平坦牺牲了实用性)。100-800Hz 频段内普通驻极体/MEMS 足够平坦。

**为什么之前不行**: ECM8000 低灵敏度 → 需最大增益 → 放大噪声底 + 位置极敏感 + 不防水。
**麦克风选型错误 = 整个 ANC 的 SNR 和路径测量都不可靠**。

## 4.8 嵌入式硬件需求方案(8spk/8mic,2026-08-12 并入)

**配置**: S=8 扬声器 / E=8 误差麦 / 1 参考麦 / L=1024 / Fs_anc=16kHz / K=S×C=8×15=120 直接权重。

**关键结论**:
- FxLMS 是算力绝对主力: 前馈 **3.48 GMAC/s**(E×S=64 路径 × L=1024,含功率归一化/leak/带通)
- 在线 Ŝ 辨识默认开,额外 **+2.23 GMAC/s** → RK3568 余量够不够的**第一开关**(嵌入式可 `GFANC_SEC_MU=0` 关,依赖出厂 64 条 Ŝ 校准)
- CNN @1Hz 仅 ~0.1 GMAC/s(前馈 ~3%),与通道数无关——"不影响降噪量"是**结构性要求**(独立核/异步 + 双缓冲)
- 内存 fp32 ≈ **4.05MB**(int8 CNN 后 ~2.8MB)
- **超当前编译上限**: `GFANC_E_MAX` 5→8、`GFANC_S_MAX` 4→8、`SC_DW_MAX` 30→120(纯代码,先做)

### 4.8.1 算力(逐模块 @16kHz,E×S=64 路径)

| 模块 | MAC/样本 | 计算 |
|---|---|---|
| 前向 anti = Wc·x | 8,192 | S×L |
| xd 更新(参考×Ŝ) | 65,536 | E×S×L |
| 功率归一化 Σxd² | 65,536 | NLMS 前置独立全遍历 |
| 梯度更新 | 65,536 | E×S×L |
| leak + Fx/err/ref 带通 | ~12,864 | S×L + E×S×64 + E×64 + 64 |
| **前馈小计** | **217,664** | **→ 3.48 GMAC/s** |
| 在线 Ŝ 辨识(默认开) | +139,264 | S×L + 2×E×S×L → **+2.23 GMAC/s** |

| 汇总(GMAC/s) | 方案1 纯前馈 | 方案2 前馈+B-1 |
|---|---|---|
| 前馈 FxLMS | 3.48 | 3.48 |
| CNN @1Hz + 反馈抵消 | 0.13 | 0.13 |
| B-1 反馈(L_fb=256~512) | — | 0.79~1.57 |
| 在线 Ŝ(可关) | +2.23 | +2.23 |
| **持续总(关Ŝ/开Ŝ)** | **3.61/5.84** | **4.40~5.18/6.63~7.41** |

> RK3568 实测 6-8 GMAC/s: 方案1 **关在线Ŝ** 余量 1.7~2.2×(偏紧),**开Ŝ <1× 不够**。夺回余量两大杠杆: ①功率归一化改滑动和(O(1)/样本,FxLMS 3.48→~2.4 GMAC/s);②关在线Ŝ。

### 4.8.2 内存 / 延迟 / I/O

| 内存用途 | fp32 |
|---|---|
| CNN 激活 + 权重 | 1.34 + 0.5 = 1.84MB |
| FxLMS(xd/Ŝ 各 256K + wc 32K) | 0.53MB |
| sub_filters [15,8,1024] | 0.49MB |

- **延迟**: 方案1 纯前馈 <3-5ms;方案2 带 B-1 **环路 <2ms 硬约束**(反馈稳定带宽 ≈0.375/τ);都需裸机/RTOS,Linux+ALSA 附加 5-10ms 不可用(仅算法验证)
- **I/O**: **9ch ADC**(1ref+8err) + **8ch DAC** @48kHz TDM/I2S;codec 3×TLV320ADC6140 + CS4382;误差麦 MEMS(INMP441/ICS-43434)

### 4.8.3 主控选型

- **方案1 纯前馈【样机首选】**: RK3568(4×A55@2GHz),实测 6-8 GMAC/s;i.MX RT1170(M7)已不够(实测 ~1 GMAC/s)
- **方案2 前馈+B-1**: i.MX 8M Plus(A55 RTOS) 或 Zynq-7000 FPGA(48 条 FxLMS 并行,确定性最强,RTL ~2-3 人月)

### 4.8.4 决策点

1. **L=1024/512**(省一半 FxLMS 算力,决定能否降主控档) 2. **B-1 要不要**(定方案1/2 与 <2ms) 3. **子滤波共享**(491KB vs 246KB) 4. **CNN int8**(内存 4.05→2.8MB) 5. **64 条 Ŝ 测量**(8×8,校准最大项) 6. **在线Ŝ 保留?**(+2.23 GMAC/s) 7. **功率归一化改滑动和?**(夺余量最大杠杆)

# 第五部分:窗户 ANC 方案与路线图

> **2026-08-13 架构转向: 闭环 → 开环前馈**。参照 SFANC-Window(Luo et al., MSSP 2024):
> 1 参考麦 + 4 扬声器(周边相对) + 4 误差麦(仅训练) + ShuffleNetV2 从 7 个固定滤波器里选 1,运行时**无误差麦**纯前馈。
> 用户倾向**开环部署**(误差麦仅安装标定用,标定完拆,设备装好后不动)。关键结论(详见 §4.3 通用换算):
> 8 扬声器 + 8 误差麦 → 20-500Hz 务实;误差麦数须 ≥ 扬声器数;量产 = 每台"安装自标定"(测 Ŝ + 训固定滤波器,自动化),
> CNN(噪声→滤波器/组合权重映射)可跨环境复用,只重标定路径相关部分(固定滤波器/子滤波器库)。
> 开环代价: 路径漂移无法自适应 → 靠"安装标定 + 设备装好后不动"兜底。

## 5.1 两条路线对比

| | **务实路线(马路噪音 20-500Hz)** | **研究级(到 1000-2000Hz)** |
|---|---|---|
| 控制单元 | **8 扬声器 + 8 误差麦**(周边,42cm 间距) | 20-24 扬声器 + 误差麦(≤17cm) |
| 参考 | **1 支参考麦窗外**(低频相干够) | **参考阵列** |
| DSP | **RK3568(4×A55,6-8 GMAC/s)** + ANC 级 codec(§4.8) | 更强 DSP/FPGA |
| 覆盖 | **20-500Hz 马路噪音主体** | 到 1000-2000Hz |
| 复杂度 | **可落地**(8 单元) | 贵,密度翻倍 |
| 预期 | 整窗能量平均 ~6-9dB(点测 ~10-15dB) | 更宽频带 |

**判断(2026-08-13)**: 8 扬声器空间采样上限 ~500Hz(§4.3),覆盖马路噪音主体(轮胎-路面噪声峰值 100-400Hz);1000Hz 需 20-24 源,空间采样代价大,留作研究级。

> **双口径定义**: ① **整窗能量平均** = 开口面多点采样的声压能量平均降噪(目标指标,可达 6-9dB);② **误差麦点测** = 优化点处的单点降噪(易高估,10-15dB)。目标"整窗声压→0"为理想极限。

## 5.2 推荐方案(马路噪音 20-500Hz)

| 项 | 选型 |
|---|---|
| **控制器** | **RK3568(4×A55@2GHz,6-8 GMAC/s)** + ANC 级低延迟 codec(§4.8) |
| **延迟目标** | **≤2ms**(逐样本:算完所有通道在 62.5µs 内) |
| **通道** | **8 扬声器 + 8 误差麦**(周边,42cm 间距,盖 123×45 窗 500Hz) |
| **扬声器** | 低频(<100Hz)需大口径/大行程(体积位移);中频小口径(4.5-8cm 高效) |
| **带通 / 控制率** | **20-500Hz** / 16kHz |
| **滤波器 L** | **512**(31Hz 分辨率够,算力减半) |
| **参考麦** | **窗外**,朝噪声源 |
| **预期** | 整窗能量平均 ~6-9dB(点测 ~10-15dB) |

**代码改动清单(当前 PC 原型 → 8 单元嵌入式)**: 通道上限 `GFANC_E_MAX/S_MAX` 5/4→**8/8**;`SC_DW_MAX` 30→**120**;L 1024→**512**;`sub_filters` 按 S=8 重训;平台移植(R-21 HAL)。

## 5.3 分阶段路线

| 阶段 | 内容 | 目标 |
|---|---|---|
| **Phase-1(已完成)** | PC 原型:灵敏度/校准/125Hz/算法优化 | 验证算法能力(窄带 17dB/宽带 10dB) |
| **Phase-1.5(硬件验证,必做)** | 实用麦选型(非 ECM8000,§4.7) + **相干性实测** + 1-2 个喇叭对消验证 | **验证全部硬件假设**后才允许进入 Phase-2:麦灵敏度/SNR/相干性/对消可行 |
| **Phase-2** | DSP 最小系统:**8 扬声器+8 误差麦** + 2ms + 窗外参考 + 20-500Hz(§4.8 硬件方案) | 整窗 20-500Hz,能量平均 ~6-9dB(点测 ~10-15dB) |
| **Phase-3(可选)** | 扩到 20-24 单元 + 参考阵列 | 到 1000-2000Hz |

## 5.4 一句话总结

> 窗户开口降噪 = **马路噪音 20-500Hz**。前馈 ANC 消它靠**低延迟(≤2ms DSP)+ 8 扬声器周边阵列(42cm 间距,空间采样上限 ~500Hz)+ 窗外参考**——8 单元务实,1000Hz 需 20-24 源(空间采样代价大)。
> 瓶颈在硬件(延迟/阵列/相干性),不是算法(PC 已证窄带 17dB/宽带 10dB 能力)。
