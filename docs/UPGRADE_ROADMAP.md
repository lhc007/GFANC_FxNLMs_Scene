## 一、已知问题与根因

### 1.1 扬声器输出音量不足

**现象**：播放马路噪声（~70 dB SPL）时，扬声器反噪声几乎听不到。

**根因**：YDM6MIC 麦克风灵敏度为 **-26 dBFS @ 94 dB SPL**。这意味着：

| 声压级 (SPL) | 场景 | 数字输出 (float32) |
|-------------|------|-------------------|
| 120 dB | 声学过载点 | 1.0 (满幅) |
| 94 dB | 摩托车近距 | 0.05 |
| 70 dB | 马路噪声 | 0.003 |
| 40 dB | 安静房间 | 0.0001 |

软件已做的补偿：
- 输入增益：10x
- Wc 硬件校准：10x
- 总增益：100x

但即使 100 倍，70 dB SPL 噪声也只能产生 ~0.01 RMS 的反噪声输出，对于消费级扬声器来说仍非常微弱。

**解决方向**：
1. **硬件前置放大器**（最直接）——在麦克风和 ADC 之间加入 20-40 dB 增益
2. **更换麦克风**——选用消费级 ANC 麦克风（灵敏度 -10 到 0 dBFS）
3. **扬声器功放**——增大 DAC 到扬声器的驱动功率

### 1.2 声反馈（啸叫）

**现象**：增益过大时扬声器输出被参考麦拾取，形成正反馈环路。

**根因**：前馈 ANC 的固有缺陷——参考麦和扬声器之间缺乏物理隔离。

**当前缓解措施**：
- 输出限幅 ±0.5
- 反馈检测（全通道 RMS 相近时自动降增益）
- 安全静音（err > ref 时 MUTE）

**解决方向**：
1. **反馈路径建模与抵消**——测量扬声器→参考麦传递函数，从参考信号中减去
2. **物理隔离**——参考麦朝外、扬声器朝内，中间加物理屏障（耳机 ANC 标准做法）
3. **自适应反馈抵消**——额外自适应滤波器实时估计并消除反馈分量

## 二、与商业 ANC 设备的功能差距

| 功能 | 商业 ANC | 本系统 | 优先级 |
|------|---------|--------|--------|
| **增益标定** | DAC→功放→扬声器 SPL 全程标定 | 手动试凑 | 🔴 P0 |
| **反馈抵消** | 扬声器→参考麦路径自适应建模 | 无 | 🔴 P0 |
| **子带处理** | 分频段独立收敛 | 全频带统一 | 🟡 P1 |
| **啸叫检测** | 频谱峰值检测 + 陷波滤波器 | 无（仅 RMS 检测） | 🟡 P1 |
| **自适应步长** | 根据信号电平动态调整 | 固定值 | 🟢 P2 |
| **双讲检测** | 检测期望信号（语音/音乐）并冻结自适应 | 无 | 🟢 P2 |
| **舒适噪声** | 添加成形噪声掩盖 ANC 伪影 | 无 | 🟢 P2 |
| **硬件看门狗** | 独立硬件监控，异常时断电 | 无 | 🟢 P2 |
| **时延补偿** | 精确补偿各通道间的采样延迟 | 依赖 PortAudio | 🟢 P2 |
| **非线性补偿** | 扬声器/麦克风非线性畸变校正 | 无 | ⚪ P3 |

### 详解

#### P0: 增益标定

**问题**：当前 `MIC_GAIN=10`、`Wc_scaling=10` 均为人工试凑值。换一套硬件就需要重新调试。

**方案**：
1. 在安静环境中播放粉红噪声（已知 SPL）
2. 测量麦克风数字输出 RMS
3. 自动计算校准系数：`gain = target_rms / measured_rms`
4. 将校准系数存入配置文件

**预期收益**：换硬件零配置，即插即用。

#### P0: 反馈抵消

**问题**：参考麦收到扬声器反噪声 → 形成正反馈 → 啸叫。

**方案**：
1. 离线测量反馈路径（扬声器→参考麦）的冲激响应 `Fb_path`
2. 运行时：`ref_corrected = ref_raw - Fb_path ⊗ anti_output`
3. 或者使用额外的自适应 LMS 滤波器在线估计反馈路径

**实现要点**：
- 反馈路径通常很短（几厘米），512 tap 足够
- 需要离线测量或在线自适应
- 抵消后参考信号中不再包含扬声器分量，可安全提高增益

**预期收益**：增益可提升 10-20 dB（10-100 倍），解决音量不足问题。

#### P1: 子带处理

**问题**：全频带统一收敛速度受限于最慢的频段。

**方案**：
1. 使用分析滤波器组将信号分解为多个子带（如 8-16 个）
2. 每个子带独立运行 FANLMS
3. 合成滤波器组重构全频带反噪声

**预期收益**：收敛速度提升 2-5 倍，各频段独立优化。

#### P1: 啸叫检测

**问题**：当前仅靠 RMS 比值检测反馈，无法区分真实噪声和反馈。

**方案**：
1. 对误差信号做 FFT，检测窄带峰值（啸叫特征）
2. 检测到啸叫频率后，用陷波滤波器陷波
3. 同时降低增益或冻结自适应

**预期收益**：大幅提升系统稳定性，允许更高的工作增益。

## 三、推荐升级顺序

```
第一阶段 (1-2 周)
├── 增益标定 (P0) —— 自动测量 + 配置文件
├── 反馈抵消 (P0) —— 离线测量 + 在线减法
└── 预期: 增益提升到 200-500x，反噪声清晰可闻

第二阶段 (2-4 周)
├── 啸叫检测 (P1) —— FFT + 陷波
├── 子带处理 (P1) —— 分析/合成滤波器组
└── 预期: 系统稳定性接近商业产品

第三阶段 (后续)
├── 自适应步长 (P2)
├── 双讲检测 (P2)

```

## 四、硬件改造建议

| 改造项 | 方案 | 预期成本 | 预期收益 |
|--------|------|---------|---------|
| 麦克风前置放大器 | MAX9814 或其他 I2S 数字 MEMS 麦克风 | ¥20-50 | 信号提升 20-40 dB |
| 扬声器功放 | PAM8403 D 类功放模块 | ¥5-10 | 驱动能力提升 |
| 物理隔离 | 3D 打印耳罩或障板 | ¥50-100 | 声反馈降低 20-30 dB |

**最佳方案**：换用 I2S 数字 MEMS 麦克风（如 INMP441，灵敏度 -26 dBFS 但 SNR 61 dBA），配 D 类功放驱动微型扬声器，参考麦和扬声器之间加物理隔离。

